# 南二环1689 · 保理银杏恋爱物语

> 一个发生在 **保定理工学院（河北省保定市南二环1689号）** 的校园恋爱视觉小说。
> 你，会计2412 的新生；他，第七排靠窗，说话很轻，怕冷，喜欢甜的东西。

网页版（手机 / 平板 / 电脑自适应），单文件静态站点，无后端、无依赖、无构建步骤。

---

## 怎么玩

打开 `index.html` 即可（也可以直接访问 GitHub Pages 的地址）。

| 操作 | 效果 |
| --- | --- |
| 点击画面 / 空格 / 回车 | 推进对话 |
| 数字键 `1`–`4` | 选择选项 |
| `H` | 对话记录 |
| `Esc` | 关闭面板 |
| 右上角 记 / 自 / 快 / 档 / ☰ | 记录、自动、快进、存档、菜单 |

手机端：点屏幕推进，右上角有同样的按钮；建议横屏时戴上耳机。

## 做了什么

- **真人主角立绘**：从你给的照片里做人物抠像（macOS Vision 人物分割 + alpha 精修 + 去边缘杂色），得到 4 组表情/姿势，另外做了脸部特写与半身，共 12 张立绘素材。
- **P 图 CG**：把抠出来的人合成进校园实景——银杏道、图书馆阶梯、雪夜、雨廊、后台、拍立得合照，共 6 张 CG，游戏内会在关键剧情弹出。
- **表情包**：6 张带台词的贴纸（“我是男的。”“我会当真的。”“+100。”）。
- **真实校园场景**：保定理工学院官网的校园实景照片（鸟瞰红砖楼群、《弟子规》雕塑银杏道、图书馆阶梯阅览区、教室、田径场、社团招新、晚会），做了统一调色与虚化处理；缺失的场景（食堂、宿舍夜景、雨廊、后台、雪夜等）用生成图补足，并统一色调。
- **剧本**：序章 + 五章 + 五种结局，17 个选择点，心动值系统，分支由心動值与关键 flag 共同决定。
- **引擎**：自写视觉小说引擎，打字机、自动/快进、对话记录、4 格存档 + 自动存档、相册解锁、人物页、设置（字号/速度/音量/天气）、键盘与触屏操作。
- **音频**：WebAudio 程序化 BGM（6 种情绪）+ 音效，零音频文件、无版权问题。
